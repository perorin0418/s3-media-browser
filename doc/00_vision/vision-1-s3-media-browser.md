# Vision

## プロジェクト概要
S3 に保存されたメディア（動画・音楽・圧縮画像）を、安全かつ効率的に閲覧・検索できる Web アプリを提供し、日々の確認・利用作業を短縮する。

## 目的（Why）
- S3 コンソールや個別ツールに依存しない、統一されたメディア閲覧体験を用意する。
- 必要な素材を素早く見つけられる状態を作り、作業ロスと確認コストを削減する。
- 運用コストを最小化し、継続運用の負荷を抑える。

## ゴール（What）
- 目的のメディアに最短手順で到達できるナビゲーションと検索体験を提供する。
- メタデータや構造を活かし、整理・把握がしやすい閲覧体験を実現する。
- 音楽フォルダを連続再生・シャッフル再生できる体験を提供する。

## 成功条件（Success Criteria）
- 動画ファイルのサムネイルと基本メタデータが一覧で確認できる。
- 動画ファイルをブラウザ上でプレビューできる。
- 音楽フォルダの連続再生・シャッフル再生が 1 操作で開始できる。
- 圧縮画像の内容をブラウザ上で確認できる。

## 非ゴール（やらないこと）
- メディアの編集・加工・変換・配信基盤の提供。
- S3 以外のストレージを中心に据えた統合管理。
- 権限管理の独自実装（既存の認可基盤を置き換えること）。
- 大量データの一括移行やデータクレンジングの実施。

## 設計・実装上の基本方針
- 使いやすさと学習コストの低さを重視する。
- 保守性と可読性を優先し、過度な最適化は避ける。
- 運用コストを抑える設計とし、不要な常時稼働を避ける。

## 技術的前提・制約
- 主たる対象ストレージは AWS S3 とする。
- 既存の認証・認可基盤に準拠し、権限の拡張や例外運用を最小化する。
- 通信や認証情報の取り扱いはセキュリティ要件に従う。
- Cognito 経由の認証を前提とする。
- フロントエンドは静的ホスティング、バックエンドはサーバーレス構成とする。
