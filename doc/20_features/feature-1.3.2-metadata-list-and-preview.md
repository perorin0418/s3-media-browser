# Feature

## Feature 名
- ID： feature-1.3.2-metadata-list-and-preview
- 所属 Milestone： milestone-1.3-PlaneSearchAndPreview

## 概要
一覧でメタデータを把握でき、ブラウザ標準で閲覧可能な形式について軽量プレビューを提供する。

## 機能要件
- 一覧で主要メタデータ（例: サイズ、更新日時、Content-Type）を表示する
- ブラウザ標準で閲覧可能な形式の軽量プレビューを提供する
- 動画/音楽/圧縮画像のプレビューは含めない
- すべてのプレビュー取得はサーバーレス API 経由で行い、未認証/未認可はフェイルクローズとする

## 非機能要件
- 性能：軽量プレビューがストレスなく表示される
- セキュリティ：プレビュー取得 API もトークン必須、認可失敗時は情報を返さない
- 可用性：プレビュー取得失敗時に一覧は継続表示し、個別エラーを返す
- 保守性：対象形式やメタデータ項目の拡張が容易

## インターフェース
- API：メタデータ一覧取得 API / プレビュー取得 API
- UI：一覧表示とプレビュー画面
- 入出力：オブジェクト指定 -> メタデータ/プレビュー

## 設計方針
- プレビューは必ず API 経由で取得し、直接 S3 参照を禁止する
- 対象形式はブラウザ標準対応に限定し、非対応形式は明示的に非表示/無効化する
- エラーハンドリングはフェイルクローズを徹底し、一覧体験を阻害しない
