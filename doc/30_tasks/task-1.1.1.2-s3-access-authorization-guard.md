# Task

## Task 名
- ID: task-1.1.1.2-s3-access-authorization-guard
- 所属 Feature: feature-1.1-1-auth-and-access-baseline

## 作業目的
既存の権限モデルに基づき、S3 の一覧/取得アクセスを確実に認可し、未許可アクセスを遮断する。

## 作業内容
- S3 の一覧/取得に対して認可ガードの適用位置と責務を確定する
- 未許可時にメタデータやオブジェクト情報を露出しない遮断経路を整備する
- 認証/認可の前提が満たされない場合はフェイルクローズで拒否する前提を整理する

## 実装制約
- 既存の権限モデルを拡張・変更しない
- 認可の判断が不確実な場合は必ず拒否する
- 権限外ユーザーにメタデータやオブジェクト情報を返さない
- 認証導線の実装や Hosted UI の設定は本 Task の対象外とする

## 変更対象
- backend/ の S3 一覧/取得 API を担当するモジュール
- backend/ の認可判定を適用する層（ガード/フィルタ/ミドルウェア相当）

## 非変更対象
- 権限モデルの定義およびルール
- Cognito/Hosted UI の設定や認証導線
- API/スキーマ仕様（interfaces）やアーキテクチャ構成

## テスト観点
- backend/ の S3 一覧/取得で権限外ユーザーが遮断されること
- backend/ の未許可時にメタデータ/オブジェクト情報が返らないこと
- backend/ の認可前提が不確実な場合にフェイルクローズとなること

## 完了条件
- 権限外ユーザーは S3 の一覧/取得にアクセスできない
- 未許可時にメタデータやオブジェクト情報が公開されない
- 認可の不確実性がある場合にフェイルクローズとなる
