# Task

## Task 名
- ID: task-1.1-2.1-secure-navigation-shell
- 所属 Feature: feature-1.1-2-secure-navigation-shell

## 作業目的
認証済みユーザーのみが到達できる安全な閲覧ナビゲーションシェルを提供し、以降の検索/プレビュー/再生体験の共通入口として機能させる。

## 作業内容
- 認証済みユーザーのみ表示される共通ナビゲーションシェルを用意する
- 初期表示時と画面遷移時に認証状態を検証する共通ガードを整備する
- 未認証/期限切れ/検証失敗/更新失敗時は既存の認証入口へ戻す導線を明確化する
- 認証状態が確定するまで閲覧 UI を描画しない制御を整える
- 主要導線（ホーム/閲覧入口/サインアウト）を備える
- 以降の機能追加が依存できる拡張可能なレイアウト構造とする

## 実装制約
- 認証状態は単一のストア/コンテキストで管理する
- 既存の認証基盤（Cognito/Hosted UI）の前提は変更しない
- API/スキーマ/アーキテクチャ構成は変更しない

## 非機能要件（Feature 整合）
- 性能: 認証状態の確認が画面遷移の体験を大きく阻害しない
- セキュリティ: 未認証時の UI/データ露出を最小化する
- セキュリティ: 認証状態が未確定の間は機密情報を DOM に出さない
- 可用性: ナビゲーションシェルの障害が認証基盤の可用性を低下させない

## 変更対象（ファイル単位）
- frontend/app.vue
- frontend/middleware/requireAuth.ts
- frontend/composables/useAuth.ts
