# システム概要

## 目的
- S3 メディアを認証・認可に基づいて安全に閲覧できるようにする。
- フロントエンドは静的ホスティング、バックエンドはサーバーレス構成とする。

## 主要コンポーネント
1. ユーザーのブラウザ
2. フロントエンド（静的ホスティング）
3. Cognito User Pool + Hosted UI
4. サーバーレス API（認可ガード）
5. S3 メディアバケット

## 主要フロー
1. ユーザーがフロントエンドを開く。
2. 未認証の場合、フロントエンドは Hosted UI にリダイレクトする。
3. Cognito がトークンをフロントエンドへ発行する。
4. フロントエンドがアクセストークンを付与して API を呼び出す。
5. API が Cognito と連携してトークンを検証し、認可を強制する。
6. API が許可されたオブジェクトまたはメタデータを S3 から取得し、応答する。

## セキュリティ境界
- すべてのメディアアクセスはサーバーレス API を経由する。
- 認証/認可が不確実な場合はフェイルクローズとする。
- すべての API リクエストにトークンが必要である。
