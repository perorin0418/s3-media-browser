# フロントエンド画面レイアウト（モック）

## 目的
Milestone 1.2 の範囲（検索・一覧・軽量プレビュー）を前提に、
フロントエンドの画面構成を共通言語として整理する。

## 構成要素
- Search Icon: タップで検索入力とメタデータフィルタを展開
- Breadcrumbs: 現在位置を短く表示
- Results List: 一覧（名称/サイズ/形式/更新日時のメタデータ）
- Preview Screen: 一覧アイテムをタップした後の遷移先
- Bottom Nav: 主要画面の移動

- drawio: frontend-layout-mock.drawio

## 設計意図
- 片手操作を前提に、縦スクロールの単一カラムで完結させる。
- 検索とフィルタは検索アイコンから展開し、常時表示を避ける。
- プレビューは一覧からの画面遷移で表示し、メイン画面の占有を抑える。
- すべてのメディアアクセスは API 経由とし、未認証時はフェイルクローズ。
